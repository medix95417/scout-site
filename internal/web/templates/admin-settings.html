Email (SMTP) Server

Where outgoing mail (password reset links, event reminders) gets sent from. Leave any field blank to fall back to its environment variable — see DEPLOY.md. The SMTP password itself isn't set here; it stays in the SMTP_PASSWORD environment variable on the server, not in the database, since it's the one real secret in this configuration. If this site sends mail via Fastmail's JMAP API instead of SMTP (MAIL_PROVIDER=fastmail-jmap), these fields don't apply — that's configured entirely through environment variables; see DEPLOY.md.
