Recognized columns (case-insensitive; spaces/underscores don't matter):

  • First Name, Last Name — required
  • Member Type — required: adult/parent/leader, or youth/scout/child
  • Role (or Position) — required, must be a role you're allowed to assign
  • Email — required for the first adult in each new family (becomes their login); ignored otherwise
  • Family Name (or Family/Household) — optional; rows sharing a family name are grouped into one family. Defaults to "<Last Name> Family" if left out
  • {{if eq .Unit.UnitType "troop"}}Patrol{{else}}Den{{end}} (or Sub Group) — must already exist on this roster; import doesn't create new {{if eq .Unit.UnitType "troop"}}patrols{{else}}dens{{end}}

A row whose email matches an existing login is added to that family. A family with no matching email and no existing family becomes a brand-new login — the temporary password for each new family is shown once on the results page, so don't navigate away before copying them down. Once a family is resolved (new or existing), a row whose first+last name already matches someone in that family is treated as already on the roster — their role is granted rather than creating a duplicate person, so re-running the same import is safe. This name match only happens within one resolved family, though: two different people who happen to share a name in different families are never confused for each other.
