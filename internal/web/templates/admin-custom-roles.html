Roles & Permissions — {{.Unit.Name}}

Every role — built-in or custom — is just a name attached to a set of capabilities. Two roles granting the same capability are treated identically everywhere on the site, so what matters is the ticks, not the name. Changing any of this is the highest-privilege action on the roster, which is why it's limited to Admin logins.

Built-in Roles

These ship with the site. What each one grants is shown below so you can check it against how {{.Unit.Name}} actually works — and change it if it doesn't match. A change applies only to this unit; anything you leave alone keeps following the site's default, including if that default improves later.
