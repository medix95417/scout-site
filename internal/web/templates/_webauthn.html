{{/* webauthn-helpers: the browser side of a security-key ceremony, shared by the two pages that run one (two-factor-settings.html to add a key, login-two-factor.html to answer with one). The server speaks the JSON go-webauthn produces, where every binary field (challenge, user id, credential ids) is base64url text. The browser API wants ArrayBuffers in and hands ArrayBuffers back, so the whole of this is converting in one direction, calling navigator.credentials, and converting in the other.
