Loads a template you built elsewhere straight into the HTML source above, exactly as written. Nothing is uploaded — the file is read here in your browser.

On save, the document wrapper (<!DOCTYPE>, <html>, <head>) is removed — an email body is a fragment — but your <style> block is kept, as are style="…" attributes and tables with their cellpadding/bgcolor/ align attributes. Scripts and event handlers are always removed. Worth knowing that Gmail ignores much of a <style> block, so anything that must survive everywhere belongs in a style="…" attribute.

Up to 5 MB, which is room for images embedded in the file itself. Worth knowing that Gmail hides anything past roughly 100 KB behind a “View entire message” link — so for a newsletter people will actually read top to bottom, linking to images beats embedding them.
